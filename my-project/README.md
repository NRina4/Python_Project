# Research Results

Проект создан в рамках лабораторной работы по публикации результатов вычислительных экспериментов.

## Назначение проекта

Проект демонстрирует воспроизводимый процесс подготовки и публикации результатов эксперимента:

**исходные данные → обработка Python → визуализация → публикация через MkDocs**

В проекте реализованы:

- сравнительный анализ генераторов статических сайтов;
- воспроизводимый pipeline обработки экспериментальных данных;
- автоматическое формирование графических результатов;
- публикация результатов в виде статического сайта.

## Структура проекта

```text
my-project/
├── data/
│   └── experiment.csv        # исходные данные эксперимента
├── docs/                     # исходники сайта
│   ├── assets/               # сгенерированные изображения
│   ├── javascripts/          # конфигурация MathJax
│   ├── index.md              # главная страница
│   ├── research.md           # сравнительный анализ генераторов
│   └── experiment.md         # результаты эксперимента
├── scripts/
│   └── generate_results.py   # обработка данных и построение графика
├── mkdocs.yml                # конфигурация MkDocs
├── requirements.txt          # зависимости проекта
└── README.md
```

## Запуск

```bash
pip install -r requirements.txt
python scripts/generate_results.py   # обновить результат эксперимента
mkdocs serve                         # локальный просмотр сайта
mkdocs build                         # сборка сайта в каталог site/
```
