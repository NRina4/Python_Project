# Публикация результатов вычислительных экспериментов

Данный сайт подготовлен в рамках лабораторной работы по публикации результатов
вычислительных экспериментов с использованием генератора статических сайтов
**MkDocs** и темы **Material for MkDocs**.

## Разделы

- **[Анализ генераторов](research.md)** — сравнительный анализ четырёх генераторов
  статических сайтов (MkDocs + Material, Sphinx + MyST-Parser, Pelican,
  Jupyter Book 2) по научному аппарату, вёрстке и эксплуатационным характеристикам.
- **[Эксперимент](experiment.md)** — воспроизводимый конвейер
  «данные → результат → сайт» и его результат.

## Конвейер публикации

```text
data/experiment.csv → scripts/generate_results.py → docs/assets/result.png → mkdocs build → сайт
```

Сборка сайта выполняется командой `mkdocs build`, локальный просмотр — `mkdocs serve`.
